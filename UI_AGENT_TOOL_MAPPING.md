## 2. Visual UI Element to AI Agent Direct Mapping

This section explicitly breaks down **which visual UI button, card, widget, or canvas element** triggers or displays output from each specific AI Agent.

| Visual UI Element | Screen / Component | Connected AI Agent / Assistant | What It Does / How It Interacts |
| :--- | :--- | :--- | :--- |
| **TORII Copilot Widget (Public Guest Mode)** | Landing / Floating (`CopilotDrawer.jsx`) | **General FAQ RAG Agent (`faqAgent.js`)** | Answers general banking queries (FD rates, card blocking, branch hours). Provides a `🔑 Log In to Solve Account Issues` action chip routing to `/kiosk/login`. |
| **TORII Copilot Widget (Authenticated Mode)** | Kiosk / Portal (`CopilotDrawer.jsx`) | **Account Triage & Proactive Ledger Solver Swarm** | Detects customer JWT session, queries PostgreSQL for active transaction holds (`ERR_PAN_MISSING_OVER_50K`), renders Section G Bottleneck Radar cards, and provides 1-Click **"⚡ Execute Agentic Fix Now"** resolution. |
| **Microphone Button** (`<button onClick={toggleMic}>`) | Kiosk Triage (`VoiceAssistant.jsx`) | **Voice Speech-to-Text (STT) Agent** | Uses browser SpeechRecognition (`en-IN`) to convert spoken customer voice into text transcript and auto-submits queries. |
| **Spoken Audio Visualizer & Speaker** | Kiosk Triage (`VoiceAssistant.jsx`) | **Voice Text-to-Speech (TTS) Agent** | Uses `window.speechSynthesis` to speak the AI agent's text answer aloud in Indian English. |
| **Chat Response Bubble** | Kiosk Triage (`KioskTriage.jsx`) | **FAQ & Intent Agent** | Displays natural language answers generated by IBM watsonx Orchestrate (or local 40-entry `faqAgent.js` fallback). |
| **Quick Action Suggestion Pills** (`QUICK_ACTIONS`) | Kiosk Triage (`KioskTriage.jsx`) | **Intent Router Agent** (`intentRouter.js`) | Clickable Neumorphic buttons (*FD interest rates*, *Block lost card*, etc.) that trigger instant AI intent classification. |
| **Proactive Compliance Hold Banner** | Kiosk Triage (`KioskTriage.jsx`) | **Ledger Diagnostic Agent** | Intercepts `pan_linked === false` or `ERR_PAN_MISSING_OVER_50K` transaction hold and renders an explicit **"⚡ Yes, Link PAN Card"** prompt. |
| **QR Code Canvas & Direct Testing Link** | Kiosk Triage (`QRCodeGenerator.jsx`) | **Ephemeral Session Token Agent** | Renders dynamic QR code & browser URL bound to a 10-minute Redis session token. |
| **Camera Capture & File Dropzone** | Mobile Upload (`DocumentUpload.jsx`) | **Gemini Vision Multimodal OCR Engine** | Uploaded document photo is sent to `@google/genai` (`gemini-flash-latest`) for field extraction, clarity scoring, specimen check, and Aadhaar privacy masking. |
| **Anti-Fraud Quality Rejection Banner** | Mobile Upload (`DocumentUpload.jsx`) | **Vision Quality Gate Guardrail** | Renders specific retry feedback (e.g., `IMAGE_CLARITY_BELOW_80_PERCENT` or `SPECIMEN_OR_DUMMY_DOCUMENT_DETECTED`) allowing up to 3 retries. |
| **Cross-Sell Recommendation Card** | Mobile Upload (`DocumentUpload.jsx`) | **Financial Advisor Agent** | Displays contextual banking recommendations (e.g. *Pre-approved Credit Card*) generated during swarm execution. |
| **AI Verification Bento Box** | Teller Dashboard (`Dashboard.jsx`) | **Gemini Vision OCR & Watchdog AML Swarm Viewer** | Shows raw AI confidence %, extracted Name/PAN, clarity score, name match score %, tampering status, and specimen flag to the teller. |
| **Secure Document Image Viewer** | Teller Dashboard (`SecureImageDisplay.jsx`) | **Secure Media Access Handler** | Displays high-resolution uploaded document with 80%–250% zoom controls via 5-minute signed storage URLs. |
| **Governance Audit Lockout Badge** | Kiosk Login (`KioskLogin.jsx`) | **Governance Sidecar Agent** (`governanceSidecar.js`) | Displays remaining OTP retry attempts and session countdown while logging immutable audit events. |

## 3. Detailed UI Screen to Subsystem Matrix

### 1. Kiosk Login Screen (`/kiosk/login`)
* **File Component**: `frontend/src/pages/kiosk/KioskLogin.jsx`
* **User Interactions**: 10-digit Account Number entry via Neo-Bento numeric keypad, 6-digit OTP entry, lockout timer display.
* **Directly Connected API Routes**:
  - `POST /api/auth/otp/request`
  - `POST /api/auth/otp/verify`
* **Direct Backend Controller**: `backend/src/controllers/authController.js`
* **Connected AI Agents & Swarms**:
  - **Governance Sidecar Agent (`governanceSidecar.js`)**: Tracks `OTP_SENT`, `OTP_FAILED`, `OTP_LOCKED`, `AUTH_SUCCESS` events with masked PII logging.
* **Connected Tools & Underlying Services**:
  - **PostgreSQL Database (`db/index.js`)**: Queries `accounts` table for account existence, `pan_linked` status, and registered email.
  - **Upstash Redis Cache (`sessionManager.js`)**: Stores 6-digit OTP with 300s TTL (`setOTP`), tracks failed attempt counters, and enforces lockout (`isOTPLocked`).
  - **Notification Gateway (`notificationService.js`)**: Dispatches email containing one-time passcode (`sendOTPEmail`).

---

### 2. Kiosk Triage & Voice Assistant Screen (`/kiosk/triage`)
* **File Component**: `frontend/src/pages/kiosk/KioskTriage.jsx`
* **Sub-Components**: `VoiceAssistant.jsx`, `QRCodeGenerator.jsx`, Neo-Bento Quick Action Chips.
* **User Interactions**: Interactive PAN Linking Consent Card, Speech/Text FAQ queries, Quick-action pills (e.g. *FD Interest Rates*, *KYC Docs*), Single-click QR generation, Direct browser handoff link.
* **Directly Connected API Routes**:
  - `POST /api/auth/qr/generate`
  - `POST /api/kiosk/query`
  - `GET /api/auth/session/validate`
  - `DELETE /api/auth/session`
* **Direct Backend Controllers**:
  - `backend/src/controllers/authController.js`
  - `backend/src/controllers/kioskController.js`
  - `backend/src/ai/intentRouter.js`
* **Connected AI Agents & Swarms**:
  - **Voice AI Assistant**: Browser Web Speech API (`SpeechRecognition` for input + `window.speechSynthesis` for spoken output).
  - **FAQ / Intent Agent (`faqAgent.js`)**: IBM watsonx Orchestrate intent classifier with local 40-entry FAQ fallback.
  - **Governance Sidecar Agent**: Logs session heartbeats and reset events (`SESSION_EXPIRED`).
* **Connected Tools & Underlying Services**:
  - **Upstash Redis Cache**: Generates single-use base64url QR tokens (`createQRToken`) with 10-minute TTL; validates and refreshes session TTL (`createKioskSession`) every 60 seconds.
  - **PostgreSQL Database**: Logs customer queries to `faq_query_log` for teller gap analysis; checks `transactions` table for `ERR_PAN_MISSING_OVER_50K` holds.

---

### 3. Mobile Document Upload PWA (`/mobile/:token`)
* **File Component**: `frontend/src/pages/mobile/DocumentUpload.jsx`
* **User Interactions**: Camera document capture, file input upload, real-time image preview, compliance error retry feedback.
* **Directly Connected API Routes**:
  - `GET /api/mobile/verify-token`
  - `POST /api/mobile/upload` (Multipart `multer` upload)
* **Direct Backend Controller**: `backend/src/controllers/mobileController.js`
* **Connected AI Agents & Swarms**:
  - **Gemini Multimodal Vision OCR Agent (`visionAgent.js`)**: Powered directly by official `@google/genai` SDK (`gemini-flash-latest`). Performs document field extraction, clarity scoring, alphanumeric heuristic correction (`fixPanHeuristics`), specimen/dummy detection, finger obstruction check, defacement detection, and Aadhaar privacy masking (`maskAadhaarPrivacy`).
  - **Watchdog AML Agent (`swarmOrchestrator.js`)**: Analyzes risk profile and flags suspicious transactions or identity anomalies.
  - **Financial Advisor Agent (`swarmOrchestrator.js`)**: Generates contextual cross-sell recommendations.
  - **Governance Sidecar Agent**: Emits audit logs for upload attempts, retries, and ticket generation.
* **Connected Tools & Underlying Services**:
  - **Supabase Object Storage (`storageService.js`)**: Persists document photo in private bucket `pan-documents` (with local dev buffer cache `localImageStore`).
  - **Upstash Redis Cache**: Non-destructive QR token validation (`getQRToken`), attempt count tracking (`upload:attempts:{accountId}`), and single-use token consumption (`consumeQRToken`).
  - **PostgreSQL Database**: Inserts pending teller ticket into `teller_tickets` table with OCR JSON payload, confidence score, and AML flags.

---

### 4. Teller Workstation Dashboard (`/teller/dashboard` or `/teller`)
* **File Components**:
  - `frontend/src/pages/teller/Dashboard.jsx`
  - `frontend/src/pages/teller/QueueList.jsx`
  - `frontend/src/pages/teller/SecureImageDisplay.jsx`
  - `frontend/src/pages/teller/ApprovalControls.jsx`
* **User Interactions**: Real-time ticket queue navigation, high-resolution document image inspection with 80%–250% zoom, Gemini OCR verification metrics review, 1-click Approve / Reject / Escalate decision controls.
* **Directly Connected API Routes**:
  - `GET /api/teller/tickets`
  - `GET /api/teller/media/:id`
  - `POST /api/teller/action`
  - `GET /api/teller/faq-gaps`
* **Direct Backend Controller**: `backend/src/controllers/tellerController.js`
* **Connected AI Agents & Swarms**:
  - **Gemini Vision OCR Bento Viewer**: Displays extracted name, PAN, ID Type, DOB, vision confidence %, name match score %, tampering status, specimen check, and rejection flags.
  - **Governance Sidecar Agent**: Emits audit events (`TICKET_APPROVED`, `TICKET_REJECTED`, `TICKET_ESCALATED`).
* **Connected Tools & Underlying Services**:
  - **Supabase Private Storage Bucket**: Generates temporary 300-second (5-minute) signed read URLs (`getSignedUrl`) for secure teller document inspection.
  - **PostgreSQL Database**: Reads pending tickets from `teller_tickets`; on approval, updates `accounts` table (`pan_linked = true`, `pan_number = ...`) and sets ticket status to `APPROVED`.
  - **Notification Gateway (`notificationService.js`)**: Dispatches decision outcome email to customer (`sendTicketStatusEmail`).

---

### 5. Teller Authentication Screen (`/teller/login`)
* **File Component**: `frontend/src/pages/teller/TellerLogin.jsx`
* **User Interactions**: Keyboard login for Employee ID and Password.
* **Directly Connected API Routes**: `POST /api/auth/staff-login`
* **Direct Backend Controller**: `backend/src/controllers/authController.js`
* **Connected AI Agents & Swarms**:
  - **Governance Sidecar Agent**: Logs `STAFF_LOGIN_SUCCESS` / `STAFF_LOGIN_FAILED` events.
* **Connected Tools & Underlying Services**:
  - **JWT Signer (`jsonwebtoken`)**: Issues an 8-hour signed `TELLER` role JWT token.
  - **Staff Credentials Registry (`STAFF_CREDENTIALS`)**: Validates employee ID and password (supports mock credential `TELLER001` / `torii2024`).

---

### 6. Sandbox / Developer OCR Test Harness (`/sandbox` or unit test runner)
* **File Component**: `tests/sandbox/` & backend sandbox routes
* **User Interactions**: Upload custom PAN image for instant Gemini OCR test output.
* **Directly Connected API Routes**:
  - `POST /api/sandbox/ocr-demo`
  - `POST /api/sandbox/seed-tickets`
* **Direct Backend Controller**: `backend/src/controllers/sandboxController.js`
* **Connected AI Agents & Swarms**:
  - **Gemini Vision OCR Agent (`visionAgent.js`)**: Directly triggers multimodal vision processing.
* **Connected Tools & Underlying Services**:
  - **Google Gen AI SDK (`@google/genai`)**: Direct API call to Gemini model.
  - **PostgreSQL Database**: Seeds mock tickets for testing approval pipelines.
